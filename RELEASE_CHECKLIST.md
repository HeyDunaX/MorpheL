# Release Checklist

Before deanonymization and public release:
- [ ] Populate `metadata/paper.yaml` with authors, venue, and DOI.
- [ ] Populate `metadata/repositories.yaml` with public GitHub/HF URLs.
- [ ] Update `LICENSE_PENDING.md` to a standard open-source license (e.g. MIT, Apache 2.0).
- [ ] Update `CONTRIBUTING.md` and `CODE_OF_CONDUCT.md` with public links.
- [ ] Ensure all references to "Anonymous" are removed from docs.
